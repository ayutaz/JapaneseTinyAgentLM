JapaneseTinyAgentLM Action 3M

日本語の依頼文 → スタックチャンの動作（JSON）。約 300 万パラメータ、ブラウザの中だけで動きます。

  • 会話のモデルではありません。返すのは次の11の動作を最大2個まで並べた JSON だけです: 首を向ける（絶対・相対、角度も可）、うなずく、首を横に振る、お辞儀、表情（7種類）、LED の色、音量、画面の明るさ。
  • 動作の依頼でない文、否定された依頼、このロボットにできない依頼には []（何もしない）を返すように学習しています。
  • 生成した token の確率の最小値（確信度）が閾値より低いときは、出力を [] に取り消します（gate）。
  • 計算は ESP32-S3 の firmware と同じ C の runtime を WebAssembly にしたもので、重みも実機と同じ INT4 の .jtlm です。入力した文はどこにも送られません。
